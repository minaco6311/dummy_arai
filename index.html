「AIにコード書かせるだけでアプリ完成するっしょｗ」
……そう思っていた時期が、俺にもありました。

こんにちは。新井株式会社のWebMaster、新井です。
最近話題の「Claude Code」、みんな使ってる？
確かにターミナルからAIを召喚してコードを生成・編集できるのは超・快・感。
でも、気づいてしまったんだ。

「環境構築やインフラ、DBの知識がないと、結局動くアプリにならなくね…？」

そう、AIは魔法の杖じゃない。
魔法を使うための『魔力（エンジニアの基礎力）』が必要なんだ！！！
当スクールでは、Claude Codeという最強の相棒を使いこなし、
真のフルスタックアプリを錬成するための【ガチのエンジニアスキル】を叩き込みます。

■□ 狂気のカリキュラム □■
（※内容はガチです。覚悟のある者だけスクロールしてください）

LEVEL.1 【召喚術】Claude Code 基礎とプロンプト・エンジニアリング
まずはターミナルにClaudeを降臨させる。的確な指示（プロンプト）の書き方、コンテキストの渡し方、ファイルの読み書き権限の掌握方法を学ぶ。
LEVEL.2 【箱庭の創造】Dockerによる絶対不変の開発環境
「俺のPCでは動いたのに…」という悲劇を終わらせる。Dockerとdocker-composeを使い、AIが生成したコードを隔離されたコンテナ内で安全に実行・検証する術を身につける。
LEVEL.3 【魔神の契約】データベース（MySQL）設計と構築
アプリの記憶を司るDB。正規化、インデックス、リレーション。Claude Codeに最適なマイグレーションファイルを生成させ、データを支配する。
LEVEL.4 【漆黒のPHP】Laravel フレームワーク連携
AIとの相性抜群なLaravelを駆使する。ルーティング、Eloquent ORMの構築、APIの実装をClaude Codeと共に爆速で組み上げ、堅牢なバックエンドを構築する。
LEVEL.5 【世界樹との接続】Git / GitHub と CI/CD
作ったアプリを世界に放つ。Gitコマンドの基礎から、GitHubへのプッシュ。そしてClaude Codeが生成したコードをレビューし、自動デプロイするまでのDevOpsを網羅。

ただAIに頼るだけの「コピペ野郎」はもう終わりだ。
Laravel、Docker、DB、GitHub。
これらを理解した上でClaude Codeを操る者だけが、次の時代を創る。
